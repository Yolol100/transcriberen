# Beveiliging

De repository bevat alleen de uitvoering. Voeg geen corpus-ZIP's, projectinhoud, toegangstokens of promptgeheimen aan Gitgeschiedenis toe.
De workflow blokkeert productieruns in een publieke repository en accepteert alleen een expliciet gepind ZIP-bestand uit een private GitHub-release.
Een ZIP uploaden in ChatGPT geeft GitHub niet automatisch toegang. Maak de repository private voordat je bronmateriaal toevoegt.
GitHub Actions-artifacts bevatten hoogstens beperkte broncitaten en statusinformatie. Vergelijk projectbronnen alleen vanuit gecontroleerde, actuele, leesbare snapshots.
Een voltooid AI-resultaat is niet hetzelfde als geverifieerde kennis. Promotie verloopt buiten de repo via de verantwoordelijke Webactueel-vakowner.
